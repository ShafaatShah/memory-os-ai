# Projects Page

## Purpose

Organises all user work into separate projects.

---

## Layout

Top Navigation

↓

Project Search

↓

Project Grid

↓

Project Details

---

## Project Search

Search projects by name.

---

## Project Grid

Displays all projects.

Each project card contains:

- Project Name
- Description
- Progress
- Last Updated
- Continue Button

---

## Project Details

Shows:

- Conversations
- Tasks
- Files
- Memories
- Recent Activity

---

## Actions

- New Project
- Rename Project
- Archive Project
- Delete Project
