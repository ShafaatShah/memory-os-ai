# Chat Page

## Purpose

The Chat page is the primary workspace where users interact with the AI.

---

## Layout

Top Navigation

↓

Conversation Header

↓

Message Area

↓

Message Input

---

## Conversation Header

Displays:

- Current Project
- Memory Status
- AI Model
- New Chat Button

---

## Message Area

Displays:

- User Messages
- AI Messages
- Time
- Memory Indicators

---

## Message Input

Contains:

- Text Box
- Upload File
- Voice Input (Future)
- Send Button

---

## Right Panel (Memory)

Shows:

- Related Memories
- Recent Files
- Suggested Tasks
