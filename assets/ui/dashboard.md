# Dashboard

## Purpose

The dashboard gives users a quick overview of their AI workspace.

---

## Section 1 - Welcome Banner

Shows:

- Welcome back
- User name
- Current workspace
- Current date

---

## Section 2 - Statistics

Four cards:

- Active Projects
- Memories Stored
- Pending Tasks
- AI Conversations

---

## Section 3 - Recent Activity

Shows the latest actions.

Examples:

- New memory saved
- Project updated
- Task completed
- Conversation started

---

## Section 4 - Quick Actions

Buttons:

- New Chat
- New Project
- Add Task
- Upload File

---

## Section 5 - Recent Projects

Displays the user's most recent projects.

Each project card shows:

- Project name
- Progress
- Last updated
- Continue button
